Descripción del proyecto

Objeto Virtual de Aprendizaje (OVA) interactivo diseñado para facilitar la comprensión de la metodología para la creación de modelos en dinámica de sistemas.

El recurso incluye fundamentos teóricos, metodología paso a paso, caso práctico de inventario de cafetería, simulador interactivo, ejercicios, juegos educativos, videos y evaluación con calificación automática.

Objetivo

Facilitar la comprensión y aplicación de la metodología para crear modelos en dinámica de sistemas mediante actividades interactivas y experimentación con escenarios.
