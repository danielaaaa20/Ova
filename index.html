1. Fundamentos de la dinámica de sistemas

La dinámica de sistemas es un enfoque de modelado que estudia cómo cambia un sistema con el tiempo, a partir de acumulaciones, flujos, relaciones causales, demoras y ciclos de retroalimentación.

Nivel (stock)

Cantidad que se acumula, como productos almacenados.

Flujo

Tasa que aumenta o disminuye un nivel, como entradas y ventas.

Retroalimentación

Cuando un cambio en una variable termina influyendo en ella misma.

Demora

Tiempo que tarda en manifestarse un efecto.

¿Por qué es importante?

Ayuda a comprender problemas complejos, anticipar consecuencias no intencionadas y comparar escenarios antes de aplicar una decisión en la realidad.

2. Metodología de creación de modelos

1. Definir el problema

Identificar qué comportamiento se quiere explicar, el horizonte temporal y la pregunta principal.

2. Delimitar el sistema

Seleccionar variables, actores, límites y supuestos relevantes.

3. Formular la hipótesis dinámica

Construir un diagrama causal que muestre cómo se relacionan las variables y sus bucles.

4. Construir el modelo de niveles y flujos

Representar acumulaciones, tasas y relaciones matemáticas.

5. Simular y verificar

Comprobar unidades, coherencia de ecuaciones y comportamiento ante condiciones extremas.

6. Validar y analizar políticas

Contrastar el modelo con el problema real, explorar escenarios y comunicar resultados y limitaciones.

La secuencia es iterativa: es normal regresar a pasos anteriores para mejorar el modelo.

Diagramas causales: polaridades y bucles

Una flecha con signo + indica que las variables cambian en la misma dirección, manteniendo lo demás constante; el signo − indica cambio en dirección contraria. Un bucle reforzador (R) amplifica una tendencia; uno compensador (B) busca contrarrestar una diferencia.

Ejemplo de bucle compensador (B)

Inventario bajo → (+) necesidad de reabastecimiento → (+) pedidos → (+) entregas → (+) inventario → (−) necesidad de reabastecimiento. Las demoras en las entregas pueden provocar oscilaciones.

Del diagrama a las ecuaciones

Inventario(t + Δt) = máx[0, Inventario(t) + (Entradas(t) − Ventas efectivas(t)) × Δt].

En el simulador, Δt = 1 día. Las ventas efectivas no pueden superar las existencias disponibles tras recibir las entradas. Se trata de un modelo didáctico discreto, no de un pronóstico calibrado con datos reales.

Verificación frente a validación

Verificar significa comprobar que el modelo está implementado según sus ecuaciones y supuestos. Validar implica evaluar si representa suficientemente bien el problema para el propósito propuesto, utilizando observaciones y juicio experto.

Buenas prácticas

Definir unidades, revisar condiciones extremas, documentar supuestos, contrastar comportamientos históricos cuando existan datos y realizar análisis de sensibilidad.

3. Ejemplo aplicado: inventario de una cafetería

Una cafetería recibe productos y vende unidades cada día. El inventario es un nivel; los suministros son un flujo de entrada y las ventas, un flujo de salida.

Regla simplificada: Inventario siguiente = máximo(0, inventario actual + entradas − ventas).

Este ejemplo representa una tienda real de forma simplificada: no considera caducidad, costos ni pedidos pendientes.
